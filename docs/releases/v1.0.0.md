# Ling Gao 校对员 v1.0.0

Ling Gao Proofreader — 报纸 PDF 版面分析与多角色 AI 校对 DSH 插件。

## 版本内容

- 单页报纸 PDF 上传，PDF.js 文字/坐标抽取 + 视觉语义分区 + 确定性文章组装；
- 报头/页眉/页脚、头条/二条/三条、正文、图说、广告等区域识别；PDF 预览区域框只显示类型/归属，**不再写置信度**，减少拥挤；
- 画布缩放/平移、区域拖动/缩放、合并/拆分、排序、文章标题/署名/正文编辑、区域归属、撤销/重做、覆盖/重叠警告；
- 显式勾选文章或整页后，后台多角色并行校对（通读/字词/成语词语/规范/事实/名词/标题/一致性），汇总裁决；
- **联网名词核查（新）**：独立 `nouns` 角色，与事实核查并行、使用独立子 Agent 和独立超时；只核查文章中机构/公司/产品/系统/项目/地名/人名头衔/特定术语是否真实存在于网络、是否有媒体或百科收录；不判断句子真假，不写“不存在”；
- 名词核查与事实核查一样列出计划：需核查名词、已检索、已核查、未核查数量，以及每个名词的实时状态；报告附名词核查清单和来源；
- 事实核查优先级清单、应查尽查、无来源不判错、来源冲突人工确认；11 分钟软截止 / 12 分钟内部截止 / 13 分钟 Host 超时；
- 完整文章 `fullText`：标题 → 副题 → 作者/记者 → 正文；名字型作者从正文折出；
- Markdown/JSON 报告导出、复制、严重度/类别/文章/角色/状态/关键词筛选；
- 不创建聊天会话，不输出改写全文，不显示 prompt；
- PDF 高清页图 + 默认自适应 + 滚轮缩放/拖动；区域检查器可关闭；最近文档可折叠；
- 中文 UI 字体/字号、必改条目 Markdown 渲染、设置返回入口等细节完善；
- 仓库包含 `.github/workflows/release.yml`：在 Actions 中手动 Run workflow 即可自动测试、构建、校验、打包并发布 GitHub Release，全程不需要手动上传资产。

## 安装

推荐 `.tgz`：DSH 侧栏 **Plugins → Add plugin**，粘贴 release 资产 URL 或本地绝对路径；`.zip` 解压后在 Add plugin 中选择含 `package.json` 的目录。需要 DSH Desktop `0.2.2-rc.5`（`<0.3.0`）。

## 已知限制

- 仅支持单页 PDF；不 OCR，扫描件/无文字层 PDF 可能无文章；
- 名词核查依赖网络搜索结果，`not_found` 只表示“当前来源中未找到”，不代表该名词不存在；`uncertain` 需要人工确认；
- 政治/敏感内容可能被 provider 内容安全拒绝，失败角色会在报告中明确标出，不伪造结果；
- 复杂报纸版面存在区域重叠/未归属；可人工校正，但 add/ignore region 尚未实现；
- 视觉模型调用有 240s 硬超时；超时会降级版面并显示 `vision-timeout` 警告；
- 文档列表/Job 状态目前是会话级，刷新页面后需重新上传。
