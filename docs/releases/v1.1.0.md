# Ling Gao 校对员 v1.1.0

Ling Gao Proofreader — 报纸 PDF 版面分析与多角色 AI 校对 DSH 插件。

## 版本内容

- **修复图说串入相邻文章正文**：视觉区域矩形会把相邻图片说明/侧栏的短文本一并包住；新版本在文章正文组装阶段识别“脱离所有正文栏的窄碎片”，将其从正文排除，同时保留缩进短行、正常段落收尾和多栏文章。已用 `2B20261122.pdf` 的 C 罗文章复核：正文不再出现“奔流音乐会”图说。
- **PDF 预览超高清**：页图渲染从 3000px/240 DPI 提升到 **6000px 长边 / 480 DPI 的超采样**；适应页面时源图约为显示宽度的 4–7 倍，浏览器缩小显示，文字边缘更清晰。页图超过 20 MiB 时会自动降采样，保证 Host 上传不失败。
- **适应页面 + 适应宽度**：默认整页适应屏幕；另有适应宽度按钮。整页 59% 缩放时页面完整显示，不再只有局部。
- **等比显示保障**：页面图使用 `object-fit: contain`，即使页面边框比例与位图存在极小舍入差异，也不会横向拉伸文字。
- 区域框仍不显示置信度，保留区域类型/归属和低置信度警告。
- 保留 1.0.0 的独立联网名词核查、事实核查、报告、取消、错误路径等能力。

## 已知限制

- 图说过滤是几何启发式：只有当短行完全脱离正文栏时才排除；正文栏内的图片说明仍按原文保留，可在人工校正中处理。
- 超高清页图会增加首次上传体积/解码内存（本样张约 15 MB），大版面页面可能接近 20 MB 限制并自动降采样。
- 仅支持单页 PDF；不 OCR；不判断图片内容。
