# Brand assets — Ling Gao 校对员

This directory holds the visual identity used by the LGProofreader DSH plugin.

## Source

- `LING_2_Graffiti.png` — original artwork provided by Ling Gao on 2026-11-18.
  - 1144 × 745 px, RGBA, transparent background.
  - Brand colors in the artwork: black `#000000`, red `#E54646`, blue `#184785`.

## Derived assets

| File | Purpose |
|---|---|
| `../../icon.png` | 512 × 512 plugin-manager / detail icon: dark navy `#0F172A` tile, oversized white **LG** monogram and a red/blue underline aligned to the letter ink. |
| `wordmark-light.png` | 780 × 252 transparent full wordmark for light theme (black letters). |
| `wordmark-dark.png` | Same wordmark with white letters for dark theme. |
| `sidebar-icon.png` | 512 × 512 compact **LG** monogram badge (no underline) for the 16/20 px sidebar/header icon. |

The LG monogram is generated by `scripts/make-brand-icons.py`; it centers the
**ink bounding box** (not the font sidebearings) so left/right outer margins are
equal at every size. The current exports measure 101/101 px white margins at
512 px (icon) and 93/93 px (sidebar); the underline is aligned to the same ink
box. The sidebar variant deliberately drops the underline so the letters stay
legible when the host renders the icon at ~20 px.

The generated files are deterministic derivatives of the source; keep the source
when changing the logo and regenerate instead of editing the PNGs by hand.

## Usage

- Plugin Manager / plugin detail icon: root `icon.png`.
- Panel header: compact badge + Chinese name `Ling Gao 校对员`.
- Panel empty state / hero: full wordmark + Chinese name + one-line tagline.
- Sidebar: `sidebar-icon.png` at the size the host requests.
- English locale: `Ling Gao Proofreader`.
